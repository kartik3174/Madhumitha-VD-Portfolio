### 1. Local LLM-Powered Semantic Retrieval System (RAG)

A privacy-focused, fully local **Retrieval-Augmented Generation (RAG)** system.

Users can provide documents and receive context-aware answers without sending their data to a cloud API.

**Technologies:**

* Local LLM
* Vector Database
* Docker
* RAG

**Architecture:**

```text
Document
   ↓
Document Processing
   ↓
Embeddings
   ↓
Vector Database
   ↓
Semantic Retrieval
   ↓
Local LLM
   ↓
Context-Aware Answer
```

## ⚙️ Getting Started

### 1. Clone the repository

```bash
git clone <repository-url>
```

### 2. Navigate to the project

```bash
cd portfolio
```

### 3. Install dependencies

```bash
npm install
```

### 4. Run the development server

```bash
npm run dev
```

### 5. Open in browser

```text
http://localhost:3000
```
